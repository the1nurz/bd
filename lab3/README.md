# Лабораторна робота №3

**Тема:** Маніпулювання даними SQL (OLTP).
**Предметна область:** бібліотека з лабораторних №1–2.

Завдання: [методичні матеріали викладача](https://github.com/ZheniaTrochun/db-intro-course/tree/master/labs/3%20-%20OLTP).

## Файли

- `setup.sql` — створення таблиць і початкових даних через незмінені файли `lab2`.
- `queries.sql` — перегляд даних, пошук, доступність та історія позик.
- `oltp.sql` — додавання, редагування, видача, повернення й видалення навчальних записів.
- `tests.sql` — перевірка початкових даних і п'ять негативних тестів.
- [REPORT.md](REPORT.md) — схема, опис запитів і фактичні результати.
- [DEFENSE.md](DEFENSE.md) — короткі пояснення для захисту.

## Запуск через psql у PowerShell

Потрібен запущений PostgreSQL. Виконуйте з кореня репозиторію. Укажіть власний шлях до `bin` та користувача замість `postgres`; пароль вводиться на запит.

```powershell
$pgBin = 'C:\Program Files\PostgreSQL\18\bin'
& "$pgBin\createdb.exe" -h localhost -U postgres library_lab3
& "$pgBin\psql.exe" -X -h localhost -U postgres -d library_lab3 -v ON_ERROR_STOP=1 -f .\lab3\setup.sql
& "$pgBin\psql.exe" -X -h localhost -U postgres -d library_lab3 -v ON_ERROR_STOP=1 -f .\lab3\queries.sql
& "$pgBin\psql.exe" -X -h localhost -U postgres -d library_lab3 -v ON_ERROR_STOP=1 -f .\lab3\oltp.sql
& "$pgBin\psql.exe" -X -h localhost -U postgres -d library_lab3 -v ON_ERROR_STOP=1 -f .\lab3\tests.sql
```

Кожна команда має завершитися без `ERROR`. Початкові кількості: `member` — 5, `author` — 5, `book` — 5, `book_author` — 6, `loan` — 5. Тести виводять `T1 PASS` … `T6 PASS` у повідомленнях.

`setup.sql` виконується один раз у порожній базі. `queries.sql`, `oltp.sql` і `tests.sql` можна повторювати на початкових даних: обидва файли зі змінами завершуються `ROLLBACK`. Для повторного створення таблиць використайте іншу порожню базу.

## Запуск через pgAdmin 4

1. Створіть порожню базу `library_lab3`, відкрийте Query Tool та увімкніть Auto-commit.
2. Виконайте повністю `../lab2/schema.sql`, потім `../lab2/data.sql`. Файл `setup.sql` призначений лише для psql.
3. Відкрийте `queries.sql`; виконуйте запити по одному й переглядайте Data Output.
4. Виконайте весь `oltp.sql` разом. Перевіряйте результати окремих `SELECT` у psql або виконуйте блоки послідовно в одному Query Tool від `BEGIN` до `ROLLBACK`.
5. Виконайте весь `tests.sql`; очікувані помилки перехоплюються, результати `PASS` видно в Messages.

Якщо виникла неочікувана помилка всередині транзакції, виконайте `ROLLBACK;` перед повторним запуском.

## Умови демонстрації

ID `1001` і `1002` зарезервовані для навчальних операцій. Дати фіксовані, щоб результат не залежав від дня запуску; Q8 показує прострочення на 25.11.2026. Для перевірки на сьогодні замініть у ньому `DATE '2026-11-25'` на `CURRENT_DATE`.

Видача захищена частковим унікальним індексом із `lab2`. Правило про обов'язкового автора кожної книги, як і в `lab2`, не гарантується самими FK: у демонстрації книгу та авторство додаємо разом, а видаляємо авторство лише разом із самою навчальною книгою.
